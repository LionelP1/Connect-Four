# Connect 4 Game 🎮🔴🟡

## Project Description
Connect 4 is a classic two-player game where players take turns dropping colored discs into a grid. The goal is to be the first to form a horizontal, vertical, or diagonal line of four discs of the same color. This web-based version of Connect 4 features an interactive board where players can click on columns to drop their discs, and it visually displays the winner when a player connects four in a row.

## Live Demo
[Connect 4 Live Demo](https://lionelp1.github.io/Connect-Four/)

## Features
- **Interactive Gameboard:** Clickable columns that allow players to drop discs into the grid.
- **Turn-based Play:** Players alternate between red and yellow discs.
- **Win Detection:** Automatically detects when a player wins by connecting four discs in a row, vertically, horizontally, or diagonally.
- **Popup Winner Message:** Displays a popup with the winner’s message and an emoji when the game ends.
- **Restart Button:** A button to restart the game and reset the board.
- **Responsive Design:** The game board is fully responsive and adjusts to different screen sizes.
